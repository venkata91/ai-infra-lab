Basics · Foundations

Building blocks

Before transformers and large language models, every neural network is built from the same handful of pieces. Get these right and the rest is just architecture.

Building blocks

Neuron

The smallest unit. Multiplies inputs by weights, adds a bias, then passes the sum through a nonlinear activation like ReLU.

y = f(w·x + b)

Layer

A row of neurons that all see the same input. nn.Linear(in, out) is the canonical example.

Model

Layers stacked end to end. A model is a function plus the parameters it has learned.

Parameters

Weights and biases. The numbers the optimizer updates. "175B parameters" is how many of these a model carries.

Depth vs width

Depth is layers stacked sequentially. Width is neurons per layer. Both increase capacity, in different ways.

Capacity

How complex a function the model can represent. Driven by parameter count, depth, width, and architecture.

Training mechanics

Forward pass

Run the model on inputs to produce outputs and a loss. Autograd silently records the operations as a graph.

Backward pass

Walk that graph in reverse, applying the chain rule. Produces a gradient of loss with respect to every parameter.

Gradient descent

Step parameters in the opposite direction of the gradient. Repeat until loss is low.

p ← p - lr · grad

Learning rate

How big a step to take. Too small means glacial training; too large means divergence. Often scheduled or adapted.

SGD & optimizers

Stochastic Gradient Descent updates on small random batches. Adam and AdamW add per-parameter adaptive rates and momentum.

Regularization

Weight decay penalizes large weights. Dropout randomly disables neurons during training. Both fight overfitting.

The training loop

1 · Forward pred = model(x)

Inputs flow through layers, producing predictions.

→
2 · Loss loss = loss_fn(pred, y)

How wrong the prediction was, as a single number.

→
3 · Backward loss.backward()

Gradients computed for every parameter via the chain rule.

→
4 · Step optimizer.step()

Parameters nudged in the direction that lowers loss. Then repeat.

Overfitting, validation, and double descent

Training loss going to zero is usually a trap. The model has memorized noise instead of learning the pattern. Hold out a validation set, watch its loss every epoch, and stop when it starts climbing.

Double descent is a modern surprise: very large overparameterized models often generalize better than mid-sized ones, even though classical theory predicts the opposite. SGD's implicit preference for flat, low-magnitude solutions is part of why scale keeps working.
