Mental model

Raw text → tokens → embeddings → transformer layers → next-token prediction.

Why it matters

Most AI infrastructure pain comes from memory, throughput, and sequence length.

How to use this

Read one concept, watch the animation, then do the exercise in Karpathy’s repo.

Tokens

Text is broken into subword pieces so the model can operate on a finite vocabulary.

Embeddings

Each token becomes a learned vector. Same token, same base vector, every time.

Attention

Every token decides which other tokens matter most for the current prediction.

Systems

Training speed is usually limited by GPU memory, batch size, and checkpointing.

Core concepts

Transformer

A transformer is a stack of layers that repeatedly refines token representations. Attention mixes information across tokens; the multi-layer perceptron (MLP) transforms each token independently. GPT means Generative Pre-trained Transformer.

Query / Key / Value

For each token, the model makes a query, key, and value (Q/K/V). Query asks what to look for, key says how to match, value carries the content.

Causal attention

GPT-style models only look left. A token can use earlier context, not future tokens. That is what makes next-token prediction work.

Residuals

Residual connections add the layer output back to the input so the network can learn small updates instead of rebuilding everything from scratch.

Animated flow

Watch the whole training loop move from input to update, one stage at a time.

1 · Input Tokens enter the model

Text becomes a sequence of token ids that the network can process.

2 · Forward pass Layers transform the signal

The model mixes information forward through embeddings, attention, and MLPs.

3 · Prediction Guess the next token

The final layer produces logits, then a probability for each candidate token.

4 · Loss Measure the mistake

Compare the guess with the target token to see how wrong the model was.

5 · Backpropagation Send error backward

Error signals flow in reverse so each layer knows how it contributed.

6 · Gradients Compute change directions

Gradients tell us how each weight should move to reduce the loss.

7 · Update Nudge the weights

The optimizer applies a small corrective step, usually with learning rate scaling.

8 · Residual connection Keep the shortcut alive

A bypass path preserves the original signal and adds the learned correction back in.

How to think about training

  • The model sees a window of tokens and predicts the next token.
  • Loss measures how wrong the prediction is.
  • Backprop computes gradients for embeddings, attention, and MLP weights.
  • The optimizer updates weights and the cycle repeats millions of times.

Hands-on curriculum

Use nanoGPT as the lab bench. Each checkpoint has a concrete exercise and a pass condition.

Checkpoint 1 · Tokens & embeddings

Open nanoGPT and find where text becomes token ids, then where token ids become vectors.

  • Exercise: trace the tokenizer input/output shape.
  • Exercise: inspect the embedding table size.
  • Pass when: you can explain why the model needs a vocab.

Checkpoint 2 · Attention & QKV

Locate the Q/K/V projections and follow one token through the attention block.

  • Exercise: identify the three linear layers.
  • Exercise: sketch what each token attends to.
  • Pass when: you can explain query vs key vs value in plain English.

Checkpoint 3 · Tiny training run

Run a small GPT training job and watch loss, speed, and checkpoints change.

  • Exercise: launch a tiny config in nanoGPT.
  • Exercise: change batch size or sequence length.
  • Pass when: you know what hurts memory and throughput.

Checkpoint 4 · Systems intuition

Compare training tradeoffs: longer context, bigger batch, more layers, more GPU memory.

  • Exercise: predict the bottleneck before you run.
  • Exercise: observe where the run slows down.
  • Pass when: you can explain why scaling is a systems problem.
