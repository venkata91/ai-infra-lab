Mental model

Raw text → tokens → embeddings → transformer layers → next-token prediction.

Why it matters

Most AI infra pain comes from memory, throughput, and sequence length.

What you should know

Embeddings, attention, Q/K/V, residuals, MLPs, loss, and optimizer steps.

Tokens

Text is broken into subword pieces so the model can operate on a finite vocabulary.

Embeddings

Each token becomes a learned vector. Same token, same base vector, every time.

Attention

Every token decides which other tokens matter most for the current prediction.

Systems

Training speed is usually limited by GPU memory, batch size, and checkpointing.

Core concepts

Transformer

A transformer is a stack of layers that repeatedly refines token representations. Attention mixes information across tokens; the MLP transforms each token independently.

Query / Key / Value

For each token, the model makes a query, key, and value. Query asks what to look for, key says how to match, value carries the content.

Causal attention

GPT-style models only look left. A token can use earlier context, not future tokens. That is what makes next-token prediction work.

Residuals

Residual connections add the layer output back to the input so the network can learn small updates instead of rebuilding everything from scratch.

How to think about training

  • The model sees a window of tokens and predicts the next token.
  • Loss measures how wrong the prediction is.
  • Backprop computes gradients for embeddings, attention, and MLP weights.
  • The optimizer updates weights and the cycle repeats millions of times.
